# Internet Mapping Activity & Web Components Match

## 1. Internet Mapping Activity

### Diagram

``` text
Your Computer
      |
      v
    Router
      |
      v
     ISP
  (Internet)
      |
      v
    Router
      |
      v
    Server
      |
      v
    Router
      |
      v
Friend's Computer
 (Another Country)
```

### Explanation

Data starts from your computer and travels through a **Router** and
**ISP**. It then passes through different routers across the Internet
and may reach a **Server**. Finally, the data travels through another
router and reaches your friend's computer in another country.

## 2. Web Components Match

  -----------------------------------------------------------------------
  Web Component                       Correct Description
  ----------------------------------- -----------------------------------
  **HTML**                            A language used to build and
                                      structure web pages.

  **URL**                             The address used to locate and
                                      access a webpage or resource on the
                                      Internet.

  **HTTP**                            A protocol used for communication
                                      between a web browser and a server.
  -----------------------------------------------------------------------

### Short Answers

-   **HTML →** Used to build and structure webpages.
-   **URL →** The address of a webpage or online resource.
-   **HTTP →** Used for communication between the browser and server.
