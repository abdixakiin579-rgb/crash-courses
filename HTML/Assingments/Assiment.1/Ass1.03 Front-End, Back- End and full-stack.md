# Front-End and Back-End Development

## 1. Role Mapping

**Website example: YouTube**

| Part | Role | What it does |
|---|---|---|
| Home page design | **Front-end** | Displays videos, buttons, menus, search bar, thumbnails, etc. |
| Video player | **Front-end** | Allows users to watch, pause, and control videos. |
| Search system | **Back-end** | Finds videos from YouTube's database. |
| User login | **Back-end** | Checks account information and authentication. |
| Video storage | **Back-end** | Stores uploaded videos and user information. |
| Comments | **Front-end + Back-end** | Front-end displays comments; back-end stores and retrieves them. |

### In short

- **Front-end** = What the user sees and interacts with.
- **Back-end** = The server, database, and logic working behind the website.

---

## 2. Tech Stack Research

### Front-end: React

**React** is a popular JavaScript library used to build interactive user interfaces and web applications. It helps developers create reusable components such as buttons, menus, forms, and pages.

**Example uses:** Facebook, dashboards, e-commerce websites, and interactive web applications.

### Back-end: Node.js

**Node.js** is a JavaScript runtime used to build server-side applications. It can handle requests from users, communicate with databases, manage authentication, and provide data to the front-end.

**Example:** When you log into a website, Node.js can process your login request and communicate with the database to verify your account.

### Summary

| Technology | Type | Main Use |
|---|---|---|
| **React** | Front-end | Building the website's user interface |
| **Node.js** | Back-end | Running server-side logic and handling requests |

**Overall:** React can handle the **front-end**, while Node.js can handle the **back-end**, allowing them to work together to create a complete web application.
